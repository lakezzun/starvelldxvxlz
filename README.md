StarvellDxvxlz

Панель продавца Starvell

Разработчик: @dxvxlz (https://t.me/dxvxlz)
GitHub: https://github.com/lakezzun/starvelldxvxlz
Сайт: https://starvell.com
Версия: 0.2.13

Это не форк FunPay Cardinal и не бот @exfador. Свой HTTP-клиент к starvell.com (cookie session) и своя Telegram-панель на pyTelegramBotAPI. UX меню похож на Cardinal, API плагинов — как у Cardinal: хэндлер получает (app, event).


Что умеет

- Мониторинг чатов и продаж Starvell
- Уведомления в Telegram: новое сообщение, новый заказ, запуск, потеря сессии
- Ответ покупателю из Telegram
- Возврат заказа из Telegram
- Автоответ по командам из чата Starvell
- Автовыдача товара после покупки (текст + файл со строками)
- Автоподнятие лотов (бамп объявлений Starvell по таймеру или кнопкой)
- Приветствие нового чата
- Плагины: один .py файл в папке plugins/
- Прокси отдельно для Starvell и отдельно для Telegram
- Смена cookie без правки файла руками
- Статистика и выгрузка логов
- Обновление с GitHub (update.bat или /update)


Установка (Windows)

1. Python 3.11 или новее, при установке галка Add to PATH.
2. Скачай репозиторий.
3. Запусти setup.bat (поставит зависимости из requirements.txt).
4. Запусти start.bat.

Первый запуск спросит:

- session cookie с starvell.com
- прокси (можно пропустить)
- интервалы опроса чатов и заказов (по умолчанию 4 и 8 секунд)
- токен бота у @BotFather
- пароль панели (минимум 8 символов, заглавные, строчные и цифра)
- прокси для Telegram, если кнопки панели падают по SSL

Cookie: открой https://starvell.com, войди в аккаунт продавца, F12 → Application / Хранилище → Cookies → starvell.com → значение session. Можно вставить всю строку Cookie целиком.

После запуска напиши боту пароль, затем /menu.


Обновление

Запусти update.bat или в Telegram: /update либо /menu → Далее → Обновление.

Бот качает свежий код с GitHub. Cookie, конфиги, товары и уже лежащие плагины не затираются; новые плагины из репозитория докладываются. После загрузки перезапусти бота командой /restart.

На Windows-хостинге без нормальной консоли бот всё равно пишет лог в logs/starvell-dxvxlz.log.

Один токен — один процесс. Если бот крутится и на хостинге, и у тебя на ПК, в логе будет конфликт Telegram (409) и Starvell начнёт отвечать 429. Оставь один экземпляр.


Команды Telegram

/menu — настройки
/profile — профиль Starvell
/logs — текущий лог
/upload_plugin — залить плагин .py
/update — обновить с GitHub
/restart — перезапустить бота
/about — о боте

Автоподнятие

Бот сам поднимает объявления Starvell вверх списка. По умолчанию каждые 30 минут. В меню: Далее → Автоподнятие лотов, либо Глобальные переключатели. Кнопка «Поднять сейчас» не ждёт таймер. Уведомления о бампе включаются в настройках уведомлений.


Автоответ

Секция = триггер. Несколько фраз через | :

[привет|здравствуйте|hello]
response = Здравствуйте! Чем помочь?
enabled = 1

Срабатывает, если сообщение покупателя совпадает с триггером или начинается с него и пробела. Регистр не важен. В тексте ответа \n = новая строка.


Автовыдача

Секция = publicId лота Starvell или точное название лота.

[ID_ИЛИ_НАЗВАНИЕ]
response = Спасибо за покупку!\n\nВаш товар:\n$product
productsFileName = stars.txt

Файл товаров: storage/products/stars.txt, одна позиция на строку. $product заменяется на столько строк, сколько в заказе quantity. Строки списываются только если найден чат покупателя; если отправка в Starvell упала, строки возвращаются в файл.

Лот привязывается в Telegram: Автовыдача → Привязать лот.
